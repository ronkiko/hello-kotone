# References

This directory contains source and visual reference material for the project.

Nothing here is canonical for RC3 by default. A reference becomes canonical
only when the Godot project explicitly adopts it in a later design decision.

`kotone-sprites-reference/` contains historical Kotone reference material,
including earlier RC1 and RC2 source material. Production copies used by the
legacy game remain under `legacy/web/assets/`.

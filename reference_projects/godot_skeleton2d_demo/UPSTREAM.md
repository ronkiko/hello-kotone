# Upstream provenance

This directory is an unmodified snapshot of the official Godot Foundation
`Skeleton2D Demo`.

- Source repository: https://github.com/godotengine/godot-demo-projects
- Source path: `2d/skeleton`
- Upstream commit: `34fc99545fc41520a958248f607101e7d0b95b05`
- Asset Store: https://store.godotengine.org/asset/godot-foundation/skeleton2d-demo/
- Minimum Godot version advertised by the Asset Store: `4.7`
- License: MIT; see `UPSTREAM_LICENSE.md` and the original `README.md`

The project is intentionally outside the repository's main `godot/` project.
Open this directory as a separate Godot project. Do not copy its generated
`.godot/` directory or its imported resources into RC3.

The upstream source files and assets must remain unchanged. Kotone-specific
observations belong in `KOTONE_REFERENCE_NOTES.md`.

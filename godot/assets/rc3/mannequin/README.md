# RC3 Kotone mannequin

This directory contains the neutral front mannequin used to prove RC3 movement
before Kotone's clothing and secondary assets are added.

- `source/` contains the coherent proportion reference awaiting user review.
- `preview/` contains checker, dark, magenta and clothed/mannequin comparison
  renders. They are QA evidence, not runtime assets.
- `parts/front/` is reserved for approved rig-ready pieces with hidden joint
  overlaps.
- `mesh/` is reserved for Godot Polygon2D mesh data after part approval.
- `mannequin_manifest.json` is the active stage gate.

The source PNG must never be treated as a production one-piece body mesh.

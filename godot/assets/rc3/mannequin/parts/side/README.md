# Side cutout parts

`m02/` is generated by `build_side_m02_assets.py`. M02 is deliberately a small
mechanical gate: one side body, one complete rigid near arm and one three-piece
leg texture instantiated twice. It proves side-facing locomotion before any
second-arm redraw or clothing pass.

`m03/` is an empty rebuild reservation. It must not inherit M02 cutouts.
